# Security and equipment control

Report suspected credentials exposure or control vulnerabilities privately to the repository administrators through the lab's internal channel. Do not include secrets in issues or pull requests.

These research applications control lab equipment. Keep services on localhost or a trusted isolated lab network; the applications have not been audited as authenticated remote-control services. Verify device identity, electrical limits, robot calibration, and emergency-stop procedures before hardware use.

No security support period or production safety certification is claimed. Tests run without connected equipment.
